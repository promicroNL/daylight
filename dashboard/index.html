About the data & how to read these charts

Faint lines show daily observations. The stronger line is the selected trailing calendar-day average, calculated from available days only. Gaps are kept when a day has no observation. No missing value is treated as zero. Hover, tap, or focus a chart and use arrow keys to inspect values. Open the daily values table for accessible exact readings.

Heart rate is the arithmetic mean of recorded samples per day, not a time-weighted average or resting heart rate. Resting heart rate comes only from the dedicated resting-heart-rate export. HRV is the exported daily RMSSD in milliseconds. Sleep uses the score date; newer Google sleep scores take precedence over legacy copies on the same date. Multiple sleeps on one date resolve to the last source row.

Dates retain the calendar date in the source timestamp (UTC for Z timestamps; unzoned legacy timestamps are not converted). Sleep-score resting heart rate is a separate source and is not substituted for daily resting heart rate. This is a personal history viewer, not a medical assessment.

To load a new export, see README.md in the dashboard folder. Original export files are never modified.
